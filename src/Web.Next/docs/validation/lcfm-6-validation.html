LCFM-6 Identity SQL models & repositories

Validation checklist for the Next.js migration identity data layer (src/Web.Next).

Acceptance

  • Demo users/roles readable without destructive migration
  • Repository tests: user lookup, role CRUD, membership
  • Password hashes never on public DTOs
  • Data access isolated from Next.js request handlers
  • ASP.NET Identity V3 hash adapter documented

Commands

cd src/Web.Next
npm ci
npm run verify
npm run test:e2e:identity
